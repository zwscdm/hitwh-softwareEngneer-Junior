# 实验4总结报告：药品管理OCR识别

## 实验概述

本实验基于MNIST数据集训练的神经网络模型进行药品管理OCR识别，包含图像分割、字符识别、性能分析和改进方案。

- **D2模型平均识别率**: 0.00%
- **D3模型平均识别率**: 3.57%
- **总体平均识别率**: 4.76%

### 2. 改进版实验结果
- **D1模型平均识别率**: 3.57%
- **D2模型平均识别率**: 0.00%

- **总体平均识别率**: 2.38%

## 问题分析

### 1. 主要问题
1. **分割算法问题**：单个数字被错误分割成多个字符
2. **模型泛化能力差**：在MNIST上训练，但在真实场景图片上表现极差
3. **数据分布差异**：MNIST是手写数字，测试图片是印刷体数字
4. **环境依赖问题**：缺少OpenCV、Tesseract等专业OCR工具

### 2. 具体表现
- 单个数字"1"被分割成"88888"、"55555"、"33333"等
- 模型倾向于预测特定数字（D1模型偏好8，D2模型偏好5，D3模型偏好3）
- 置信度普遍较低（0.1-0.4之间）

#### 方案B：改进图像预处理
```python
# 更好的图像预处理
def advanced_preprocess(image):
    # 1. 去噪
    image = cv2.medianBlur(image, 3)
    
    # 2. 增强对比度
    clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8,8))
    image = clahe.apply(image)
    
    # 3. 形态学操作
    kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (2,2))
    image = cv2.morphologyEx(image, cv2.MORPH_CLOSE, kernel)
    
    return image
```

## 实验结论

### 1. 主要发现
- 基于MNIST的模型在真实场景图片上表现极差
- 图像分割算法需要大幅改进
- 专业OCR库（如EasyOCR、PaddleOCR）效果会更好

### 2. 改进效果
- 原始版本：4.76%识别率
- 改进版本：2.38%识别率（实际上更差，说明分割问题更严重）
- 预期使用专业OCR库：>80%识别率

### 3. 建议
1. **短期**：使用EasyOCR或PaddleOCR
2. **中期**：改进图像预处理和分割算法
3. **长期**：收集真实数据，训练专门的OCR模型
