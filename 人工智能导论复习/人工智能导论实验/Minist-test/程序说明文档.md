# 实验4：药品管理OCR识别 - 程序说明文档

## 项目概述

本项目实现了基于MNIST数据集训练的神经网络模型进行药品管理OCR识别，包含完整的图像分割、字符识别、性能分析、改进方案和多种OCR库对比。

## 功能特性

### 1. 图像预处理
- **灰度化转换**：将彩色图像转换为灰度图像
- **对比度增强**：提高图像对比度，便于字符分割
- **噪声去除**：使用中值滤波去除图像噪声
- **自适应二值化**：使用Otsu算法或固定阈值进行二值化

### 2. 字符分割
- **垂直投影分割**：基于垂直投影的字符分割算法
- **连通组件分析**：使用OpenCV连通组件分析进行字符检测
- **点阵字体优化**：专门针对点阵字体的闭运算+开运算处理
- **智能合并算法**：合并被错误分割的字符片段
- **形态学操作**：去除噪点和连接断裂的字符
- **字符归一化**：将分割后的字符统一调整到28x28像素
- **字符居中**：确保字符在图像中心位置

### 3. 模型识别
- **三个模型对比**：使用D1、D2、D3三个不同数据量训练的模型
- **数据增强**：旋转、缩放、噪声等数据增强技术
- **集成预测**：使用多个增强样本进行投票预测
- **置信度评估**：计算每个预测的置信度

### 4. 结果分析
- **详细报告**：生成包含每个字符识别结果的详细报告
- **性能统计**：计算每个模型和总体的识别率
- **错误分析**：分析识别错误的原因和模式
- **改进建议**：提出具体的性能改进方案

## 技术实现

### 网络架构
```python
class Net(nn.Module):
    def __init__(self):
        super(Net, self).__init__()
        # 卷积层（2层，符合≤5层要求）
        self.conv1 = nn.Conv2d(1, 10, kernel_size=5)      # 第1层卷积：1→10通道
        self.conv2 = nn.Conv2d(10, 20, kernel_size=5)     # 第2层卷积：10→20通道
        self.conv2_drop = nn.Dropout2d()                   # Dropout2d层
        
        # 全连接层（2层，符合≤2层要求）
        self.fc1 = nn.Linear(320, 50)                      # 第1层全连接：320→50
        self.fc2 = nn.Linear(50, 10)                       # 第2层全连接：50→10
    
    def forward(self, x):
        # ReLU激活 + 2x2最大池化
        x = F.relu(F.max_pool2d(self.conv1(x), 2))        # 28×28→12×12
        x = F.relu(F.max_pool2d(self.conv2_drop(self.conv2(x)), 2))  # 12×12→4×4
        
        # 展平 + 全连接层
        x = x.view(-1, 320)                                # 20×4×4=320
        x = F.relu(self.fc1(x))                            # 320→50
        x = F.dropout(x, training=self.training)           # Dropout正则化
        x = self.fc2(x)                                    # 50→10
        
        return F.log_softmax(x, dim=1)                     # LogSoftmax输出
```

## 实验结果

### 识别率统计
| 方法 | 平均识别率 | 特点 |
|------|------------|------|
| D1 (MNIST 10%) | 34.96% | 数据量适中，性能相对较好 |
| D2 (MNIST 1%) | 5.63% | 数据量较少，严重过拟合 |
| D3 (MNIST 0.1%) | 2.67% | 数据量极少，泛化能力极差 |
| 改进版D1 | 34.96% | 优化分割算法，点阵字体处理 |
| 改进版D2 | 5.63% | 小样本学习挑战巨大 |
| 改进版D3 | 2.67% | 模式崩塌现象严重 |

### 性能分析
1. **MNIST模型局限性**：训练数据与测试数据分布差异大（手写数字 vs 印刷数字）
2. **小样本学习挑战**：数据量减少导致性能急剧下降，D2和D3模型出现严重模式崩塌
3. **分割质量影响**：图像分割质量直接影响识别效果，点阵字体分割是难点
4. **超参数重要性**：学习率0.01+动量0.9是最佳配置，超参数调优显著影响性能
5. **网络结构影响**：2层卷积+2层全连接结构适合MNIST，但需要平衡模型复杂度
6. **改进算法效果**：针对点阵字体的分割优化显著减少了过度分割问题

## 改进方案

### 1. 数据增强
- **基础增强**：旋转、缩放、对比度、亮度调整
- **高级增强**：Mixup、CutMix、噪声注入
- **生成数据**：使用GAN生成更多训练数据
- **领域适应**：引入外部无监督数据

### 2. 模型改进
- **网络架构**：使用ResNet、DenseNet、Transformer等先进架构
- **注意力机制**：引入空间注意力和通道注意力
- **迁移学习**：使用预训练模型进行迁移学习
- **集成学习**：多模型投票和加权融合

### 3. 预处理优化
- **分割算法**：改进字符分割算法，使用连通域分析
- **点阵字体处理**：闭运算连接离散点，开运算去除噪声
- **智能合并**：基于距离和重叠度的字符合并算法
- **二值化方法**：使用Otsu、自适应阈值等先进方法
- **字符归一化**：统一字符大小和位置
- **去噪处理**：使用形态学操作去除噪点
- **中文路径支持**：使用PIL解决OpenCV中文路径问题

### 4. 后处理优化
- **语言模型**：使用N-gram模型进行后处理
- **置信度过滤**：设置置信度阈值过滤低质量预测
- **投票机制**：多模型投票决定最终结果
- **规则引擎**：使用规则验证识别结果

### 5. 专业OCR库
- **EasyOCR**：深度学习OCR，识别效果最佳
- **PaddleOCR**：中文OCR库，数字识别也有优势
- **Tesseract**：传统OCR，稳定可靠
- **集成方案**：结合多个OCR库的结果
