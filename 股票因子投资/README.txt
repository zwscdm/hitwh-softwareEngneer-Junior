1.ipynb后缀的文件是给出的因子提交流程的例子，包括数据处理等。通过jupyter插件可以正常浏览。AI说这个具有参考意义，当时直接丢给AI让他看着学了（
2.四种数据类型：行情数据，技术指标数据，资金流数据，基本面数据。通俗解释可以参考股票因子投资知识点
3.股票因子如何理解。因子可以理解为一个指标，通过一些方面进行股票的预测。利用老师要求的数据类型，设计一个公式，得出一个新的评估系统。
4.代码流程：upload_demo_intern文件下共有三个核心代码：pyalpha,pyconfig,pyupload.主要是成功运行pyupload,把另外两个文件提交到服务器上，编译并运行。因此，需要在本地调试好pyupload的运行环境，另外两个的不用处理。pyupload.pyd需要成功被upload扫描。pyalpha,pyconfig提交到服务器运行后，会通过回测系统，在本地生成bt_result文件（一些照片）
5.alpha挖掘手册为作业要求，不用完全实现。基础算子为operator.pyd二进制文件中的一些常见方法。在编写pyalpha可以进行调用（本地没法调试，需要运行upload，在服务器上运行后反馈并调试）
